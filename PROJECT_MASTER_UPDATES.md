## 🏛️ Executive Overview & Mission

**RakhshaSutra (रक्षासूत्र)** is an enterprise-ready, citizen-accessible **Digital Defense Operating System (DDOS)** built to unify fragmented security telemetry into an actionable, explainable, and continuously monitored posture.

Unlike siloed cybersecurity scanners that only present raw error codes or dense logs, RakhshaSutra delivers:
- **Zero-Friction Citizen Defense:** Instant scans for phishing, dark web exposure, malicious URLs, and suspicious SMS with plain-language explanations (Guardian Mode) and immediate escalation paths to the Indian **1930 Cyber Financial Fraud Helpline** and **CERT-In**.
- **Enterprise SOC Command Center:** Attack surface mapping, real-time threat intelligence feeds, CVSS 3.1 & EPSS vulnerability triage, incident containment checklists, and active deception honeytokens.
- **Explainable Threat Heuristics:** Built-in AI Copilot with dynamic persona switching (Non-technical citizen vs. Tier-3 SOC analyst).

## ⚡ Comprehensive Feature Inventory by Domain

### 4.1. Attack Surface Management (ASM) & Asset Inventory
- **Passive Enumeration:** Scans public Certificate Transparency (CT) logs (`crt.sh`) and passive DNS records without sending aggressive probe traffic that alerts attackers.
- **Asset Catalog:** Auto-categorizes apex domains, subdomains, reverse proxies, and cloud storage endpoints.
- **Risk Score Algorithm:** Assigns each asset an exposure rating (0–100) based on TLS validity, open ports, exposed headers, and public CVE linkages.
- **Dedicated View:** Available at `/attack-surface` with real-time discovery triggers and CSV/JSON asset inventory export.

### 4.2. Security Asset Graph 2.0 (Relational Topology)
- **Node Classification:** Graph nodes represent domains, subdomains, IP blocks, TLS certificates, CVEs, and open incidents.
- **Edge Relationship:** Graph edges represent relationships like `resolves_to`, `hosted_on`, `issued_by`, and `exploited_in`.
- **Side-Sheet Inspector:** Clicking any node slides open a detailed telemetry drawer showing DNS records, ping status, open ports, and remediation actions.
- **Interactive Controls:** Zoom, pan, search filtering, and node group isolation.

### 4.3. Vulnerability Intelligence Center (CVE, CVSS, EPSS)
- **Authoritative Metrics:** Every vulnerability includes CVSS 3.1 base score, severity rating (Low, Medium, High, Critical), and EPSS probability percentile.
- **Affected Assets Matrix:** Identifies which software package (e.g., OpenSSL, Nginx, libwebp, Linux kernel) and system nodes are vulnerable.
- **Lifecycle Tracking:** Workflows for updating status: `OPEN` ➔ `INVESTIGATING` ➔ `MITIGATED` ➔ `RESOLVED` ➔ `ACCEPTED_RISK`.
- **Reference Feeds:** Direct hyperlinks to NIST NVD, MITRE CVE, and exploit proof-of-concepts.

### 4.4. SOC Alerts Pipeline & Real-Time Ingestion
- **Event Sources:** Aggregates alerts from certificate expiry warnings, DNS drift, typosquatting domain registrations, malware IP hits, and honeytoken triggers.
- **Intelligent Deduplication:** Merges identical alerts within time windows, tracking hit counts and threat confidence.
- **SOC Triage Workflow:** Move alerts seamlessly through `NEW`, `ACKNOWLEDGED`, `INVESTIGATING`, and `RESOLVED` states with single-click actions.

### 4.5. SOC Incident Response Center & Containment
- **Incident Declaration:** Escalate critical alerts into formal security incidents with severity classifications.
- **Containment Checklists:** Step-by-step actionable containment items (e.g., Revoke API Keys, Block Malicious Subnet, Isolate Host, Trigger Honeypot).
- **Forensic Timeline:** Timestamped audit trail recording analyst actions, forensic findings, and containment state changes.
- **National Emergency Playbooks:** Built-in 1-click reporting templates for **CERT-In** (Indian Computer Emergency Response Team) and the **1930 Cyber Fraud Helpline**.

### 4.6. Security Posture Engine 2.0 (11 Defense Vectors)
The Posture Engine scores security readiness across 11 key defense vectors:
1. **Identity & Access Management (IAM):** MFA enforcement, passkey support, session TTLs.
2. **Endpoint Protection:** EDR presence, patch status, device posture.
3. **Network Perimeter:** Firewalls, DDoS protection, open ports.
4. **Web & TLS Defense:** SSL/TLS 1.3, HSTS, secure cipher suites.
5. **Cloud Infrastructure:** Bucket permissions, IAM least-privilege, audit logging.
6. **Application Security:** WAF rules, CORS configuration, dependency audit.
7. **Email Security:** Strict SPF records, DKIM signing, and DMARC `reject` policies.
8. **Data Exposure & Dark Web:** Password leaks, dark web mentions, public paste dumps.
9. **Vulnerability Management:** Unpatched CVEs, mean-time-to-remediate (MTTR).
10. **Continuous Monitoring:** Real-time logging, uptime tracking, SIEM forwarding.
11. **Incident Readiness:** Response playbooks, regular drill execution, contact escalations.
- **"Improve My Score":** Real-time recommendations engine projecting exact point increases for each corrective action.

### 4.7. Universal Security Search Engine (`Ctrl + K`)
- High-speed fuzzy search across **6 distinct entity types**:
  - Assets, Domains & IP Addresses
  - CVE Vulnerabilities
  - SOC Alerts
  - Incidents & Cases
  - Threat Intel IOCs
  - Forensic Dossiers & Reports
- Keyboard shortcut `Ctrl + K` (or `Cmd + K` on macOS) accessible anywhere in the application.

### 4.8. Security Report Generator & Dossier Exports
Generates publication-ready reports across 6 formal templates:
1. **Executive Summary:** High-level posture overview for C-level leadership.
2. **Comprehensive Security Assessment:** Complete technical audit of all vectors.
3. **Attack Surface & Shadow IT Report:** Inventory of exposed assets.
4. **Vulnerability Audit:** Detailed CVE listings, affected nodes, and remediation steps.
5. **Incident Post-Mortem:** Root cause analysis, containment timeline, and lessons learned.
6. **Phishing & Fraud Dossier:** Evidence packet with headers, registrar details, and screenshots for legal authorities.
- **Formats:** Downloadable as formatted Markdown, structured JSON telemetry, and printable PDF formats.

### 4.9. Hourly Cyber Threat News & Security Dispatches
- **Live RSS Aggregation:** Collects breaking alerts from:
  - CERT-In Security Advisories
  - CISA KEV (Known Exploited Vulnerabilities Catalog)
  - The Hacker News
  - BleepingComputer
  - DarkReading
- **Smart 1-Hour Caching:** 3600-second TTL in-memory cache preventing rate-limiting while guaranteeing fresh hourly security dispatches.
- **Breaking Threat Ticker:** Animated ticker at the top of the Command Center with modal deep-dives.

### 4.10. Production Emergency Hub & Rapid Panic Actions
- Accessible via the **Emergency Center** (`/emergency`):
  - **1-Click Panic Button:** Prominently displays immediate action items for victims of active financial or identity fraud.
  - **1930 Helpline Quick-Dial:** Direct trigger for India's National Cyber Crime Reporting Portal.
  - **Emergency Network Quarantine:** One-click session kill-switch, API token revocation, and lockouts.
  - **Evidence Freezing Vault:** SHA-256 evidence hashing tool ensuring chain of custody for digital forensics.

### 4.11. Multi-Vector OSINT Reconnaissance Suite
- **Domain & DNS Intel:** A, AAAA, MX, TXT, CNAME, NS, SOA record queries with nameserver vulnerability audits.
- **WHOIS & Registrar Telemetry:** Registrar name, creation date, expiry date, contact emails, and DNSSEC validation.
- **IP & ASN Geolocation:** Country, city, latitude/longitude coordinates, ASN number, and ISP classification.
- **Email Security Validation:** Automated DNS checks verifying SPF record syntax, DKIM selectors, and DMARC enforcement.
- **Social Profile Recon:** Instagram GraphQL profile probe extracting public account metrics, avatar hashes, and metadata.

### 4.12. Dark Web Breach Monitor & k-Anonymity Probes
- **Zero-Knowledge Password Verification:** Implements SHA-1 k-Anonymity hashing (Cloudflare & HaveIBeenPwned architecture). Only the first 5 characters of the SHA-1 hash are transmitted; matching occurs locally in memory to guarantee zero credential leakage.
- **Account & Identity Exposure:** Scans known breach databases for compromised emails, usernames, and corporate domains.
- **Remediation Guides:** Step-by-step password rotation and account recovery playbooks.

### 4.13. Active Honeytoken Deception Network
- **Decoy Generation:** Create decoy assets to trap unauthorized intruders:
  - Fake AWS Access Key IDs & Secrets (`AKIA...`)
  - Decoy Database Connection Strings (`postgres://...`)
  - Fake JWT Bearer Tokens
  - Canary URLs & Webhooks
- **Tripwire Triggers:** As soon as an attacker attempts to use a honeytoken, an instant high-priority alert is generated with attacker IP, User-Agent, and timestamp.

### 4.14. Autonomous Registrar Takedown Swarm
- **Automated Abuse Detection:** Resolves the authoritative abuse reporting email for any hosting registrar, ISP, or cloud provider (e.g., Namecheap, Cloudflare, GoDaddy, AWS).
- **RFC 2822 Complaint Generation:** Assembles a legally binding cease-and-desist letter detailing trademark violations, phishing evidence, WHOIS discrepancies, and malicious hosting.
- **Mail Dispatcher:** Direct mailer capability to dispatch notices directly from the platform.

### 4.15. Real Geographic Cyber Attack World Map
- **Leaflet Cartography:** Real-world map powered by OpenStreetMap and satellite tiles.
- **Live Laser Attacks:** Curved ballistic trajectories with glowing amber attack arrows, vector chevrons, and shockwave explosion rings at target nodes.
- **Salvo Blitz Engine:** Simulated cyber warfare attack waves mimicking real-world APT campaigns (DDoS, Ransomware, Brute-Force, Exfiltration).
- **SOC Fullscreen & Audio:** Audio feedback for incoming strikes, tactical HUD overlays, and city focus hotspots (e.g., New Delhi, Bengaluru, Mumbai, Washington, London, Tokyo, Frankfurt).

### 4.16. RakshaAI Security Copilot 2.0 (Dual Mode)
- **Guardian Mode:**
  - Designed for citizens, students, and non-technical staff.
  - Avoids intimidating acronyms; explains threats with simple analogies.
  - Directs users to safety checklists and helpline numbers.
- **Analyst Mode:**
  - Designed for SOC analysts and incident responders.
  - Outputs MITRE ATT&CK techniques, CVSS severity metrics, raw packet indicators, and firewall remediation scripts.

### 4.17. Universal Cross-Browser Extension (MV3)
- **Cross-Browser Compatibility:** Validated on Google Chrome, Microsoft Edge, Brave, Opera, Mozilla Firefox, and Apple Safari.
- **Manifest V3 Architecture:**
  - Service worker background lifecycle (`background.js`).
  - Pre-navigation request inspection using `chrome.webRequest` / `declarativeNetRequest`.
  - In-page dynamic DOM badge injection (`content.js`, `content.css`).
  - Download guard intercepting risky file downloads before execution.
  - Standalone popup dashboard (`popup/popup.html`) with 1-click quick scans.

### 4.18. Multi-Tenancy, Granular RBAC 2.0 & SaaS Engine
- **Multi-Tenant Organizations:** Manage corporate workspaces with seat counts, invite links, and billing management.
- **Granular RBAC 2.0 Roles:**
  - `owner`: Full root access, billing, and team deletion.
  - `admin`: User administration, SOC triage, and asset configuration.
  - `analyst`: Incident response, threat investigation, and report generation.
  - `developer`: API key management, webhook configuration, and scan execution.
  - `viewer`: Read-only access to dashboards and posture scores.
- **Entitlements & Quotas:** Tiered subscription management (Free vs. Pro vs. Enterprise) with daily scan counters, midnight reset mechanisms, and rate limiters.

## 🗄️ Database Schema, Models & Modernization

The data layer uses SQLAlchemy 2.0 async models compatible with both PostgreSQL and SQLite. In the September 2026 update, all foreign key relationships were modernized with explicit `foreign_keys` arguments to ensure zero migration warnings and full integrity:

- **`User` (`users`):** `id`, `email`, `hashed_password`, `full_name`, `role`, `tier`, `is_active`, `scans_used_today`, `last_scan_date`, `created_at`.
- **`Organization` & `OrgMember`:** Multi-tenant hierarchy, seat quotas, invitations, and role-scoped permissions.
- **`Asset` & `SecurityAsset`:** Domain names, subdomains, IPs, open ports, exposure ratings, discovery sources, and verification status.
- **`Vulnerability` (`vulnerabilities`):** CVE IDs, titles, descriptions, CVSS 3.1 base score, EPSS probability, affected software, and remediation status.
- **`SecurityAlert` (`security_alerts`):** Alert title, severity, category, deduplication key, occurrence count, confidence score, and triage status.
- **`Incident` & `IncidentNote`:** Incident title, classification, severity, containment checklist state, and analyst notes.
- **`ApiKey` (`api_keys`):** Hashed API keys, prefix tags, rate limits, total requests, and active status.
- **`AuditLog` (`audit_logs`):** Immutable record of all system events, user actions, IP addresses, and timestamps.
- **`DeceptionToken` (`deception_tokens`):** Honeytoken decoy credentials, token types, and breach alerts.
- **`ThreatIntel` (`threat_intel`):** Malicious IPs, URLs, domain signatures, and threat actors.
- **`SecurityReport` (`security_reports`):** Stored report records, generated formats (PDF/MD/JSON), and download hashes.


### 2. Nginx Production Configuration (`nginx.conf`)
- Reverse proxies `/api/` traffic to the FastAPI backend.
- Serves the compiled React bundle with gzip compression and strict security headers:
  - `X-Frame-Options: SAMEORIGIN`
  - `X-Content-Type-Options: nosniff`
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Content-Security-Policy` tuned for Vite and Leaflet tiles.
- SPA fallback ensures all deep links route gracefully without 404 errors.

### 3. Client-Side Hash Routing Fallback
- Configured React routing to maintain zero 404s across diverse hosting providers (Vercel, Netlify, Cloudflare Pages, GitHub Pages, Render, and offline local previews).

### 4. Cloud Run / Render Deployment
- `cloudbuild.yaml` provides Google Cloud Build triggers for automated container builds and continuous deployment to **Google Cloud Run**.
- `render.yaml` enables 1-click blueprint deployment to Render.
